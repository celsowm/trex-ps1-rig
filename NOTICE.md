# NOTICE — Source asset attribution

## Original asset

The dinosaur model included in this repository — the geometry (`source/dino/dino.obj`),
UV layout, material list (`source/dino/dino.mtl`), and the six texture pages
(`source/dino/DINO[n]_p00.png`) — originates from the **PlayStation Developer's
Demo CD** (the "Models" section, "Dino").

That material is © Sony Computer Entertainment Inc. / Sony Interactive
Entertainment. All rights reserved by its respective owners.

It is included in this repository **for preservation, research, and educational
purposes only**, so that the rigging and animation work below can be reproduced
on the original, unaltered asset (1:1: no retopology, no texture edits).

## Original work in this repository

The following are original work by the repository author
([@celsowm](https://github.com/celsowm)) and are **not affiliated with,
sponsored by, or endorsed by Sony**:

- `rig_trex_blender.py` — Blender armature, vertex group, and weight computation
- `animate_trex.py` — reconstructed walk-cycle animation
- `diagnose_rig.py`, `lib_trex.py`, `test_rig_math.py`, `run_all.sh` — tooling
- All generated outputs in `output/` and previews in `diagnostics/`
